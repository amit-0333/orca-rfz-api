## 🧠 About Me

I'm Amit, a **data science and machine learning** practitioner with a data analysis foundation, now moving into **AI Engineering**: taking a machine learning or LLM idea, building it end to end, and *testing whether it actually works*.

I started with Python, DSA, SQL, EDA and data visualization. Over the past year I moved from notebooks into real systems: APIs, data pipelines, LLM integrations and experiment tracking. Everything I study ends up as a repo here, so this profile is a record of that progress.

### 🔨 What I build

- **LLM applications.** [CareerPulse](https://github.com/amit-0333/careerpulse) pulls live job data from 4 APIs, calculates real skill-match scores, and gives an LLM those scores (not guesses) to produce career guidance. It comes with a FastAPI backend, MLflow tracking, drift detection and Docker. [Flights NL Query Dashboard](https://github.com/amit-0333/flights-nl-query-dashboard) lets you ask questions about flight data in plain English (Gemini + SQL), with anomaly detection, a governed metrics layer and 25 automated tests.
- **Data tools.** [LabelFlow](https://github.com/amit-0333/labelflow) is an LLM-powered data annotation platform that I'm building right now.
- **Statistical work.** Forecasting and causal inference, where being rigorous matters more than getting a nice-looking number.

### 🔬 How I work

I care about whether a result is *true*, not just whether it looks good.

In my [UPI forecasting project](https://github.com/amit-0333/upi-forecast-uncertainty), I caught my own data leakage mid-project and fixed it. I also showed that a model with a better in-sample fit did far worse on unseen data (holdout MAPE jumped from 11.44% to 86.24%), and I reported that "100% interval coverage" was a warning sign, not a win.

In my [causal inference repo](https://github.com/amit-0333/causal-inference-ab-test-diff-in-diff), I ran an A/B test with proper significance testing and replicated Card & Krueger (1994) using difference-in-differences.

Each of these projects has a `PROJECT_JOURNEY.md` that documents the mistakes and limitations, not just the wins.

### 🎯 Where I'm headed

- **Now:** building LabelFlow, studying deep learning, and preparing for AI engineering roles
- **Next:** more LLM projects (RAG, evaluation, agent workflows) and a live deployment of CareerPulse
- **Looking for:** entry-level roles in AI engineering, ML engineering, data science or data analysis

## ⭐ Featured Projects

### 1. 🧭 [CareerPulse](https://github.com/amit-0333/careerpulse): AI Career Assistant

> An end-to-end ML and LLM system that tells you how well you actually match real jobs, and what to learn next.

Most job tools show you listings without telling you how well you fit. CareerPulse fetches live jobs daily, calculates a **real** skill-match percentage with a set-intersection algorithm, and hands those real scores to an LLM, so the career advice is grounded in data instead of hallucinated.

- 📄 Parses a PDF resume to extract skills automatically
- 🎯 Match scoring against live jobs from 4 APIs, with skill-gap analysis
- 🗺️ Generates a personalized 90-day learning roadmap, cover letters and interview questions
- 🔁 Online learning model (River) that updates as new jobs arrive
- 📉 Drift detection that triggers retraining when the job market shifts
- 🧪 MLflow experiment tracking and a scheduled daily pipeline (APScheduler)

**Stack:** `Python` `FastAPI` `Streamlit` `River` `spaCy` `MLflow` `Groq LLM` `SQLite` `Docker`
**Status:** 🟡 Live deployment coming soon

---

### 2. 🏷️ [LabelFlow](https://github.com/amit-0333/labelflow): LLM-Powered Data Annotation Platform

> A data annotation workspace with an LLM in the loop.

An annotation platform for creating labeling projects, managing tasks and exporting labeled data, built around an LLM to speed up the labeling workflow. It has user authentication, project and task management, templates and export modules.

**Stack:** `Python` `LLM`
**Status:** 🔵 In active development

---

### 3. ✈️ [Flights NL Query Dashboard](https://github.com/amit-0333/flights-nl-query-dashboard)

> Ask questions about Indian flight data in plain English and get answers from SQL.

A Streamlit dashboard where an LLM (Gemini) turns natural language into SQL queries over Indian flight data. It also includes cross-sectional anomaly detection and a governed metrics layer, so the numbers stay consistent. Backed by **25 automated tests**.

**Stack:** `Python` `Streamlit` `Gemini API` `MySQL` `SQL`

---

### 4. 📈 [UPI Forecast with Honest Uncertainty](https://github.com/amit-0333/upi-forecast-uncertainty)

> Forecasting India's monthly UPI transaction volume, then testing the forecast against data the models never saw.

ARIMA vs Prophet with 95% confidence intervals, evaluated on a real 12-month holdout.

| Model | MAE (Mn) | RMSE (Mn) | MAPE |
|---|---|---|---|
| ARIMA(1,1,1) | 2,105 | 2,536 | 11.44% |
| Prophet (tuned) | 2,012 | 2,423 | 11.25% |

- Caught and fixed **data leakage** in my own hyperparameter tuning
- A trend-term experiment improved in-sample fit but pushed holdout MAPE from 11.44% to **86.24%**
- Showed why "100% interval coverage" can be a red flag, not a win

**Stack:** `Python` `statsmodels` `Prophet` `pandas` `scikit-learn`

---

### 5. 🔬 [Causal Inference: A/B Testing & Difference-in-Differences](https://github.com/amit-0333/causal-inference-ab-test-diff-in-diff)

> Proving whether a change actually *caused* an outcome, not just happened alongside it.

- **Cookie Cats A/B test (90,189 users):** moving the paywall gate from level 30 to 40 lowered 7-day retention (19.02% → 18.20%, p = 0.0016), while 1-day retention showed no significant change. I also found and removed an extreme outlier.
- **Card & Krueger (1994) replication (410 restaurants):** difference-in-differences with robust standard errors found no evidence that New Jersey's minimum wage hike reduced employment (+2.75 FTE per restaurant).

**Stack:** `Python` `SciPy` `statsmodels` `pandas` `Matplotlib`
